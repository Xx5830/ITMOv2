# Proposal

## Why

Пользователь не может быстро найти задачу в графе: список растёт, а искать приходится глазами. Бэкенд получает поиск `GET /tasks?q=` (см. `specs/002-title-search/`), UI должен им воспользоваться.

## What Changes

- В левую панель добавляется поле «Поиск по названию».
- Ввод отправляется на сервер с задержкой 300 мс; граф перерисовывается по найденным задачам.
- Пустое поле возвращает полный список.
- Состояния: загрузка, «ничего не найдено», ошибка 400 под полем, сетевая ошибка через баннер фичи B.
- Результат поиска не перезаписывает кеш «последнего известного списка» в localStorage.

## Capabilities

### New Capabilities
- `task-search-ui`: поле поиска по названию и поведение интерфейса при разных ответах сервера.

### Modified Capabilities

## Impact

- Код: `app/static/index.html` (разметка и JS). Бэкенд не затрагивается.
- Контракт: `specs/002-title-search/contracts/search-contract.md`.
- Не затрагиваются: слайдеры симуляции, добавление/удаление задач, валидация.
