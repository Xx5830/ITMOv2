# task-search-ui Specification

## Purpose
Позволяет пользователю искать задачи по части названия прямо в интерфейсе графа и понимать результат при любом ответе сервера.

## Requirements

### Requirement: Поиск по названию из панели
Интерфейс SHALL содержать поле поиска; после паузы ввода 300 мс он SHALL запрашивать `GET /tasks?q=<текст без крайних пробелов>` и показывать в графе только полученные задачи.

#### Scenario: Ввод запускает поиск
- **WHEN** пользователь вводит `milk` и 300 мс не вводит ничего
- **THEN** отправляется запрос с `q=milk`, граф показывает только найденные задачи

#### Scenario: Быстрый ввод даёт один запрос
- **WHEN** пользователь печатает `m`, `i`, `l`, `k` с паузами короче 300 мс
- **THEN** отправляется один запрос с `q=milk`

#### Scenario: Пустое поле возвращает все задачи
- **WHEN** пользователь стирает текст в поле или вводит только пробелы
- **THEN** отправляется запрос без `q`, граф показывает полный список, запрос с пустым `q` не отправляется

### Requirement: Состояния результата
Интерфейс SHALL различать пустой результат, ошибку клиента и сбой сети.

#### Scenario: Ничего не найдено
- **WHEN** сервер отвечает 200 и `[]`
- **THEN** показывается сообщение «ничего не найдено», граф пуст

#### Scenario: Ошибка 400
- **WHEN** сервер отвечает 400 с `detail`
- **THEN** под полем показывается текст `detail`, граф не меняется

#### Scenario: Сбой сети
- **WHEN** запрос не завершился за 3 секунды или произошла сетевая ошибка
- **THEN** показывается баннер «не удалось связаться с сервером», граф остаётся прежним

### Requirement: Кеш не загрязняется поиском
Интерфейс SHALL записывать в localStorage только ответ на запрос без `q`.

#### Scenario: Результат поиска не попадает в кеш
- **WHEN** сервер отвечает на запрос с `q=milk`
- **THEN** сохранённый в localStorage «последний известный список» не меняется
