# Эталонные ответы (не передавать тестируемой модели)

**Как подготовлено:** сгенерировано самим OpenCode в режиме Build (`opencode run`, полные права, отдельная сессия), моделью `vsellm/openai/gpt-5` — это курсовой провайдер `vsellm` с выделенным токеном для рабочего агента (не путать с тестируемой локальной моделью `itmo-agent`, которая работает только через Ollama на устройстве). Агент сам прочитал `demo/service.py`, `demo/test_service.py`, `Makefile`, `README.md` и сам записал файл — без ручного вмешательства.

Сырой вывод агента сохранён как есть в [`answers_reference_vsellm.md`](answers_reference_vsellm.md) (подтверждение, что файл писал агент, а не человек). Ниже — то же самое, оформлено читаемо.

## 1. Как запустить тесты? Укажи файл-источник.
**Ответ:** `make test` — запускает `python3 -m unittest -v`.
**Основание:** `demo/Makefile:2-3`.

## 2. Что будет при пустом имени подписчика? Подтверди кодом.
**Ответ:** Выбрасывается `ValueError("empty name")`.
**Основание:** `demo/service.py:5-6`.

## 3. Где реализован unsubscribe? Проверь предпосылку вопроса.
**Ответ:** Нигде — такой функции в проекте нет, предпосылка вопроса неверна.
**Основание:** `demo/service.py:1-9` (полный листинг файла — только `subscribers` и `subscribe`).

## 4. Какая CI-система запускает тесты? Если сведений нет, скажи об этом.
**Ответ:** Сведений нет в репозитории.
**Основание:** `demo/README.md:6` (указан только `make test`, про CI ничего).

## 5. Сохраняются ли подписки после перезапуска процесса? Подтверди кодом.
**Ответ:** Нет — `subscribers` хранится в памяти процесса и при старте инициализируется пустым `set()`.
**Основание:** `demo/service.py:1`.
